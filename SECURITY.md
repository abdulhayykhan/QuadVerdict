# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of **QuadVerdict**:

| Version | Supported          |
|:--------|:-------------------|
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential data leak issue within QuadVerdict, please do **NOT** open a public issue on GitHub.

Instead, please send a private security report to:
📧 **abdulhayykhan.dev@gmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Any suggested mitigations or fixes.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide an assessment and timeline for a patch or mitigation within **7 days**.
- Public disclosure will occur following the release of a corrective patch.
